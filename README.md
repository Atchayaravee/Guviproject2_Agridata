
# 🌾 AgriData Explorer

## 📌 Project Overview
AgriData Explorer is a data analytics project that explores Indian agriculture using **Python (Pandas + Plotly), SQL (MySQL), and Power BI**.  

The project answers **25 analytical questions** about crop production, yield, and cultivated area in India:
- **15 questions answered with Python (EDA + interactive charts using Plotly).**
- **10 questions answered with SQL + Power BI (interactive dashboard).**

---

## 🔑 Objectives
- Perform exploratory data analysis (EDA) using Python and Plotly.
- Write SQL queries to extract key agricultural insights.
- Build an interactive **Power BI dashboard** with slicers, KPI cards, and charts.
- Provide actionable insights into agricultural productivity trends.

---

## 📂 Project Workflow

### 1️⃣ Data Preparation
- Cleaned and standardized the raw dataset.
- Handled missing values, duplicates, and negative values.
- Fixed naming inconsistencies (e.g., state_names,rice_production_1000_tons)
- Used **MySQL** for database storage and querying.
- Loaded data into **Pandas** for EDA and visualization.

---

### 2️⃣ Python EDA (15 Questions)
- Implemented exploratory data analysis using:
  - **Pandas** → Data cleaning, transformation, grouping, and aggregations.
  - **Plotly** → Interactive visualizations (line charts, bar charts, scatter plots, heatmaps)
- Answered **15 analytical questions** (e.g., production trends, top states, yield comparisons).
- Generated a standalone Python script (`eda.py`) containing all plots.

---

### 3️⃣ SQL + Power BI Dashboard (10 Questions)
- Wrote **SQL queries** in MySQL for 10 additional questions.
- Exported query results into Power BI as separate tables.
- Established relationships between query tables and the main agricultural dataset.
- Designed an **interactive dashboard**:
  - Year & State slicers
  - KPI cards for area and yield
  - Line, bar, and scatter charts
  - Dashboard title and layout

---

### 4️⃣ Results
✅ **Python cleaning and EDA** – 15 insights with interactive Plotly charts.  
✅ **Power BI Dashboard** – 10 questions answered interactively with dynamic slicers.  
✅ **Comprehensive Insights** – Combination of Python EDA + BI dashboard ensures both detailed analysis and executive-level summaries.
